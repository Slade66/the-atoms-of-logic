# NetworkManager 与 nmcli

## 一、核心概念

- **NetworkManager：** Linux 上管理网络配置的工具，负责统一管理网络设备和网络连接配置。

- **nmcli：** `nmcli` 是 NetworkManager 的命令行工具，可以控制 NetworkManager、查看网络状态、创建/显示/编辑/删除连接配置，以及启用或停用网络连接。

- **device vs connection：**

    - **device：** `device` 是硬件或虚拟网卡，是 Linux 看到的真实网络设备，例如 `ens33`、`eth0`、`enp0s3`、`wlan0`。

    - **connection：** `connection` 是 NetworkManager 保存的网络配置档案，用来定义一张网卡“该怎么连网”；它不是网卡本身，可以命名为 `Wired connection 1`、`System eth0`、`home-wifi`、`office-static-ip`，同一张网卡也可以在公司使用静态 IP、在家使用 DHCP。

## 三、修改已有静态 IP 配置

- **适用场景：** 如果已有连接配置可以直接改，就使用 `nmcli connection modify` 修改这份连接配置。

- **生效前提：** NetworkManager 管理的是 `connection profile`，也就是一套网络配置；配置激活到 `device` 上之后才真正生效。

- **示例参数：** 假设网卡名是 `ens33`，连接名是 `Wired connection 1`，IP 地址是 `192.168.1.50/24`，网关是 `192.168.1.1`，DNS 是 `223.5.5.5 8.8.8.8`。

- **修改命令：** 把已有连接改成手动 IPv4，并写入 IP、网关、DNS，同时禁用 IPv6。

    ```bash
    sudo nmcli connection modify "Wired connection 1" \
      ipv4.method manual \
      ipv4.addresses 192.168.1.50/24 \
      ipv4.gateway 192.168.1.1 \
      ipv4.dns "223.5.5.5 8.8.8.8" \
      ipv6.method disabled
    ```

- **重新启用：** 修改连接配置后，需要重新启用连接，让新配置生效。

    ```bash
    sudo nmcli connection up "Wired connection 1"
    ```

## 四、新建静态 IP 连接

- **适用场景：** 新建连接更适合服务器，因为它不会破坏原来的 DHCP 配置。

- **示例参数：** 假设网卡名是 `ens33`，新连接名是 `static-ens33`，IP 地址是 `192.168.1.50/24`，网关是 `192.168.1.1`，DNS 是 `223.5.5.5 8.8.8.8`。

- **新增命令：** 使用 `nmcli connection add` 新增一个绑定到 `ens33` 的静态 IP 连接，并设置自动连接。

    ```bash
    sudo nmcli connection add type ethernet ifname ens33 con-name static-ens33 \
      ipv4.method manual \
      ipv4.addresses 192.168.1.50/24 \
      ipv4.gateway 192.168.1.1 \
      ipv4.dns "223.5.5.5 8.8.8.8" \
      ipv6.method disabled \
      connection.autoconnect yes
    ```

- **启用连接：** 新建后启用这份连接配置。

    ```bash
    sudo nmcli connection up static-ens33
    ```

## 五、连接控制命令

- **停用连接：** 使用 `connection down` 停用某个连接配置，但网卡可能会被其他自动连接配置重新拉起来。

    ```bash
    sudo nmcli connection down static-ens33
    ```

- **断开网卡：** 使用 `device disconnect` 断开某张网卡，并阻止它自动重连。

    ```bash
    sudo nmcli device disconnect ens33
    ```

- **重新连接：** 使用 `device connect` 或 `device up` 重新连接某张网卡。

    ```bash
    sudo nmcli device connect ens33
    sudo nmcli device up ens33
    ```

## 六、连接配置的存储

- **定义与位置：** `connection profile` 是 NetworkManager 保存的网络连接档案，可能存为 `keyfile`（`.nmconnection`）或 `ifcfg-*` 文件。

- **RHEL 9 / RHEL 10：** 默认存放在 `/etc/NetworkManager/system-connections/xxx.nmconnection`，使用 `keyfile` 格式。

- **RHEL 7 / RHEL 8：** 大部分在 `/etc/sysconfig/network-scripts/ifcfg-xxx`，部分可能在 `/etc/NetworkManager/system-connections/` 下。

- **位置查询：** 用 `nmcli -f TYPE,FILENAME,NAME connection` 查看 connection 与实际文件路径的对应关系。

    ```bash
    [root@kylin116 ~]# nmcli -f TYPE,FILENAME,NAME connection
    TYPE      FILENAME                                                                 NAME
    ethernet  /etc/sysconfig/network-scripts/ifcfg-enp6s18                             enp6s18
    bridge    /var/run/NetworkManager/system-connections/br-1d55faa2a33e.nmconnection  br-1d55faa2a33e
    bridge    /var/run/NetworkManager/system-connections/br-308816a43f91.nmconnection  br-308816a43f91
    bridge    /var/run/NetworkManager/system-connections/br-3682765ae17f.nmconnection  br-3682765ae17f
    bridge    /var/run/NetworkManager/system-connections/br-9ea9d7648078.nmconnection  br-9ea9d7648078
    bridge    /var/run/NetworkManager/system-connections/br-d11ae68c8128.nmconnection  br-d11ae68c8128
    bridge    /var/run/NetworkManager/system-connections/docker0.nmconnection          docker0
    bridge    /var/run/NetworkManager/system-connections/docker_gwbridge.nmconnection  docker_gwbridge
    bridge    /var/run/NetworkManager/system-connections/br-8c993e58a249.nmconnection  br-8c993e58a249
    bridge    /var/run/NetworkManager/system-connections/br-e223bda38aee.nmconnection  br-e223bda38aee
    ```

- **手工修改后刷新：** 手工修改 `keyfile` 后，NetworkManager 不会自动重新读取磁盘上的 profile；先用 `nmcli connection reload` 让 NetworkManager 读取变更，再用 `nmcli connection up <连接名>` 重新激活连接。

    ```bash
    sudo nmcli connection reload
    sudo nmcli connection up <连接名>
    ```
