# `ens192` 和 `ifcfg` 文件的绑定关系

## 一、配置文件位置

- **配置位置：** 以 RHEL/CentOS 的老式网络配置为例，网卡配置通常写在 `/etc/sysconfig/network-scripts/ifcfg-*` 文件里；如果网卡接口名叫 `ens192`，对应配置文件通常是 `ifcfg-ens192`。

## 二、配置文件示例

- **典型内容：** `ifcfg-ens192` 里面可能长这样：

    ```bash
    TYPE=Ethernet
    BOOTPROTO=static
    NAME=ens192
    DEVICE=ens192
    ONBOOT=yes
    IPADDR=192.168.1.10
    PREFIX=24
    GATEWAY=192.168.1.1
    DNS1=8.8.8.8
    HWADDR=00:50:56:aa:bb:cc
    ```

## 三、关键字段含义

- **DEVICE：** `DEVICE=ens192` 表示“这个配置要应用到 `ens192` 这张网卡上”。

- **ONBOOT：** `ONBOOT=yes` 表示开机时启用这张网卡。

- **IP 配置：** `IPADDR`、`PREFIX`、`GATEWAY`、`DNS1` 分别表示 IP、掩码、网关、DNS。

- **HWADDR：** `HWADDR`（hardware address，硬件地址，大白话就是“绑定这张网卡的 MAC 身份证号”）表示这个配置还要匹配指定 MAC 地址。

## 四、绑定逻辑

- **接口匹配规则：** `ifcfg` 文件不会自动“认识”网卡，而是通过 `DEVICE=ens192` 指定要配置的接口；系统会先看是否存在名为 `ens192` 的接口，如果文件里还写了 `HWADDR`，还必须同时匹配对应的 MAC 地址。
