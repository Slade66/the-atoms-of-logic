# 使用 Expect 自动执行 ssh-copy-id 并应答 SSH 密码

## 一、为什么需要 Expect

- **自动化阻碍：** 在终端里执行 `ssh-copy-id` 时，命令会停下来等待输入 SSH 密码；脚本、CI 或 AI 自动化流程无法像人一样观察终端并手动输入。要在无人值守的场景中完成公钥上传，就需要能自动应答这类提示的工具。

- **交互提示类型：** 除了 SSH 密码，同类阻碍还包括 `sudo` 的 `Password:`、安装脚本的 `Continue? [y/N]` 等。

## 二、Expect 介绍

- **Expect 是什么：** `expect` 是一个自动化交互式命令行程序的工具，可理解为命令行的“自动应答机器人”。它读取程序输出，模拟“看到提示 → 输入回答 → 继续等待”：等待指定提示，再发送预先设定的输入。例如匹配 SSH 的 `password:` 后自动发送密码和回车，从而让 `ssh-copy-id` 在无人值守时完成公钥上传。

- **历史与安装：** `expect` 由 Don Libes 在 NIST 开发，约 1990 年诞生，基于 Tcl。Tcl 是一门脚本语言，全称常被解释为 `Tool Command Language`，不是 Linux 内核内置组件；Linux 上需要通过 `apt` 或 `yum` 安装 `expect`，macOS 通常预装 `expect`。

## 三、Expect 的关键指令

- 四步对应四条指令：启动命令 → 等提示 → 发回答 → 等到结束。中间「等提示 → 发回答」可以重复多轮，直到命令结束。

- **`spawn`：** 启动一个交互式程序，对应在终端里执行命令。

- **`expect`：** 等待程序输出中出现指定文本或正则表达式。匹配到后再 `send`；若还有下一条提示，就继续 `expect`。

- **`send`：** 向交互式程序发送字符串；`\r` 表示回车。

- **`expect eof`：** 等待子进程输出文件结束标记，表示命令已经结束。等的是进程结束，不是下一条提示。

## 四、用 Expect 自动化执行 ssh-copy-id

- **完整脚本：** `ssh-copy-id` 默认会停下来等待 SSH 密码。Expect 负责启动命令、匹配密码提示、发送密码，并等到公钥上传完成。`spawn` 启动 `ssh-copy-id`，`-i` 指定要上传的公钥文件，相当于在终端里执行同一条命令。

    ```bash
    expect <<'EOF'
    set timeout 60
    spawn ssh-copy-id -i ~/.ssh/id_ed25519.pub -o StrictHostKeyChecking=accept-new user@host
    expect {
      -re "(?i)password:" { send "YOUR_PASSWORD\r" }
      timeout { puts "timeout waiting for password prompt"; exit 1 }
    }
    expect {
      eof { }
      timeout { puts "timeout after password"; exit 1 }
    }
    EOF
    ```

- **首次连接的主机密钥处理：** `StrictHostKeyChecking=accept-new` 会自动接受首次出现的主机密钥，减少首次连接的确认提示；如果已存在的主机密钥发生变化，仍然会拒绝连接。

- **匹配密码提示：** `expect` 等待 SSH 输出密码提示；`-re` 表示使用正则表达式匹配，`(?i)` 表示不区分大小写，因此可以匹配 `password:` 或 `Password:`。匹配到后 `send "YOUR_PASSWORD\r"` 发送密码和回车，让远程命令继续执行。

- **等待结束与超时：** 第二个 `expect` 等待 `eof`，确认 `ssh-copy-id` 进程已经结束，避免脚本在公钥上传完成前提前退出。两个 `expect` 块都有 `timeout` 分支；如果 60 秒内没等到密码提示，或发送密码后命令没有结束，就打印错误并以状态码 `1` 退出。

## 五、Expect 中的转义

- **字面量 `$` 的转义：** 在 Expect 的双引号字符串中，`$` 用于变量替换；如果密码中包含字面量 `$`，直接写入可能会被当作变量处理，因此要使用 `\$` 表示字面量 `$`。例如密码 `Pass$word` 在双引号字符串中应写成：

    ```tcl
    send "Pass\$word\r"
    ```
- **回车写法：** `\r` 表示回车，通常放在发送内容的末尾，让远程命令认为用户已经按下 Enter。
