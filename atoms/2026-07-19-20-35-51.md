# Go 如何生成 32 位随机数

## 一、完整实现

- **实现代码：** 使用 `crypto/rand` 生成 4 个随机字节，再用 `binary.BigEndian.Uint32` 将它们转换为 `uint32`。

    ```go
    package identity

    import (
        "crypto/rand"
        "encoding/binary"
    )

    func newRandom() uint32 {
        var buf [4]byte
        rand.Read(buf[:])

        return binary.BigEndian.Uint32(buf[:])
    }
    ```

- **生成流程：**

    1. 创建 4 字节数组。
    2. 使用安全随机数据填满数组。
    3. 将 4 个字节解释为一个 `uint32`。

    ```text
    crypto/rand
        ↓
    [18, 171, 52, 205]
        ↓
    binary.BigEndian.Uint32
        ↓
    313210061
    ```

## 二、生成随机字节

- **字节数组：** `var buf [4]byte` 创建一个长度固定为 4 的数组，初始值为 `[0, 0, 0, 0]`。一个 `byte` 包含 8 位，因此 4 个字节正好包含 32 位。

- **切片转换：** `buf` 的类型是 `[4]byte`，而 `rand.Read` 接收 `[]byte`。`buf[:]` 为整个数组创建切片视图，不复制数据，因此 `rand.Read` 可以直接修改原数组。

- **随机读取：** `rand.Read(buf[:])` 从操作系统的安全随机源读取 4 个字节，并写入 `buf`。不同调用可能得到不同结果。

    ```text
    [1, 2, 3, 4]
    [217, 43, 156, 8]
    ```

- **命名含义：** `Read` 沿用 Go 中 `io.Reader` 的命名习惯，表示“从数据源读取字节并写入缓冲区”。这里的数据源是安全随机源。

    ```go
    file.Read(buf) // 从文件读取字节
    conn.Read(buf) // 从网络连接读取字节
    rand.Read(buf) // 从安全随机源读取字节
    ```

- **返回处理：** 在 Go 1.26 中，`crypto/rand.Read` 保证填满切片且不返回错误；底层随机源异常时，程序会直接终止，因此这里可以忽略返回值。

## 三、转换为 32 位整数

- **转换目的：** `rand.Read` 得到的数据类型是 `[4]byte`，而后续计算需要一个 `uint32`。`binary.BigEndian.Uint32` 只改变数据的解释方式，不改变其随机性。

- **转换示例：** 假设 `rand.Read` 生成了以下 4 个字节。

    ```go
    buf := [4]byte{18, 171, 52, 205}
    ```

    | 字节 | 十进制 | 二进制 |
    | --- | ---: | --- |
    | `buf[0]` | 18 | `00010010` |
    | `buf[1]` | 171 | `10101011` |
    | `buf[2]` | 52 | `00110100` |
    | `buf[3]` | 205 | `11001101` |

    `BigEndian` 把前面的字节放在整数的高位，四个字节依次组成一个 32 位二进制数：

    ```text
    00010010 10101011 00110100 11001101
    高位                            低位
    ```

    ```go
    random := uint32(buf[0])<<24 |
              uint32(buf[1])<<16 |
              uint32(buf[2])<<8 |
              uint32(buf[3])
    ```

    `binary.BigEndian.Uint32` 封装了上面的位移与组合过程：

    ```go
    random := binary.BigEndian.Uint32(buf[:])
    // random == 313210061
    ```
