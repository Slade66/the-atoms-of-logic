# Go 切片删除元素的常见写法

## 一、删除最后一个元素

### 1.1 写法与执行过程

- **实现方式：** Go 的切片没有专门的 `delete` 方法。删除最后一个元素时，可以通过重新切片，将切片的结束位置缩短一位。

    ```go
    slice = slice[:len(slice)-1]
    ```

- **执行过程：** 假设切片包含 `10`、`20`、`30`、`40` 四个元素。

    ```go
    slice := []int{10, 20, 30, 40}
    ```

    ```text
    下标：       0   1   2   3
    元素：      10  20  30  40
    len(slice)：4
    ```

    1. `len(slice) - 1` 的结果是 `3`，因此原表达式等价于 `slice[:3]`。

    2. `slice[:3]` 保留下标范围 `[0, 3)`，也就是下标为 `0`、`1`、`2` 的元素。

    3. 操作结果为 `[10, 20, 30]`，最后一个元素 `40` 不再属于当前切片。

### 1.2 操作本质与安全边界

- **操作本质：** 重新切片只是把切片的长度缩短一位。底层数组中的 `40` 可能仍然存在，只是已经超出当前切片的可见范围；从使用效果上看，相当于删除了最后一个元素。

- **安全边界：** 如果切片为空，`len(slice) - 1` 的结果是 `-1`，切片操作会发生 `panic`。

    ```go
    slice := []int{}
    slice = slice[:len(slice)-1] // panic
    ```

    删除前需要先确认切片中存在元素。

    ```go
    if len(slice) > 0 {
        slice = slice[:len(slice)-1]
    }
    ```

## 二、删除指定下标的元素并保持顺序

### 2.1 写法与执行过程

- **实现方式：** 假设待删除元素的下标是 `i`，可以将该位置前后的两个切片重新拼接起来。

    ```go
    slice = append(slice[:i], slice[i+1:]...)
    ```

- **执行过程：** 假设原切片为 `[10, 20, 30, 40]`，待删除元素的下标为 `1`，目标是删除元素 `20`。

    ```go
    slice := []int{10, 20, 30, 40}
    i := 1
    ```

    1. 取出删除位置之前的元素。`slice[:i]` 等价于 `slice[:1]`，结果为 `[10]`，其中不包含下标 `i` 对应的元素。

    2. 取出删除位置之后的元素。`slice[i+1:]` 等价于 `slice[2:]`，结果为 `[30, 40]`。

    3. 使用 `append` 拼接两部分，最终得到 `[10, 30, 40]`。其中，`...` 会把第二个切片展开成一个个元素，依次传给 `append`。

        ```go
        append(slice[:i], slice[i+1:]...)
        // 等价于
        append([]int{10}, []int{30, 40}...)
        // 展开后相当于
        append([]int{10}, 30, 40)
        ```

### 2.2 顺序与性能

- **顺序保证：** 这种写法会保持剩余元素原来的顺序。

- **时间复杂度：** 删除位置之后的元素需要依次向前移动，因此时间复杂度为 `O(n)`。
