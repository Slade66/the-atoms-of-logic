# PowerShell 中的 `param()` 与 `[CmdletBinding()]`

## 一、职责区别

- **`[CmdletBinding()]`：** 让脚本或函数拥有官方 Cmdlet 风格的公共参数。

- **`param(...)`：** 定义脚本或函数能够接收哪些外部参数。

## 二、`[CmdletBinding()]`

- **核心作用：** 添加 `[CmdletBinding()]` 后，脚本或函数会自动支持 PowerShell 提供的公共参数。

- **常见参数：**

    - `-Verbose`

    - `-Debug`

    - `-ErrorAction Stop`

    - `-WarningAction SilentlyContinue`

- **声明方式：** 这些公共参数由 PowerShell 统一提供，不需要在 `param()` 中自行声明。

### 2.2 类比解释

- **普通函数：** 像一家路边小店，由你自己决定有哪些参数。

- **高级函数：** 添加 `[CmdletBinding()]` 后，就像加入了连锁店标准，自动拥有统一的收银、投诉、日志和错误处理流程。

### 2.3 `-Verbose` 示例

- **函数定义：**

    ```pwsh
    function Test-Demo {
        [CmdletBinding()]
        param()

        Write-Verbose "正在执行详细步骤"
        Write-Host "正常输出"
    }
    ```

- **默认运行：**

    ```pwsh
    Test-Demo
    ```

    ```text
    正常输出
    ```

- **详细运行：**

    ```pwsh
    Test-Demo -Verbose
    ```

    ```text
    VERBOSE: 正在执行详细步骤
    正常输出
    ```

## 三、`param()`

### 3.1 声明内容

- **核心作用：** `param(...)` 用来声明参数的名称、类型、是否必填以及校验规则。

- **结构关系：** 参数声明负责定义“接收什么”，调用命令负责提供“传入什么”。

    | 内容 | 含义 |
    | --- | --- |
    | `[int]` | 参数值必须能够转换为整数 |
    | `$A` | 参数变量名 |
    | `$B` | 参数变量名 |
    | `-A 10` | 调用时向 `$A` 传入 `10` |
    | `-B 20` | 调用时向 `$B` 传入 `20` |

### 3.2 脚本参数

- **参数声明：** 在脚本中使用 `param()` 定义 `$Name` 参数。

    ```pwsh
    param(
        [string]$Name
    )

    Write-Host "你好，$Name"
    ```

- **脚本调用：** 通过 `-Name` 向 `$Name` 传入“小泽”。

    ```pwsh
    .\hello.ps1 -Name "小泽"
    ```

- **运行结果：**

    ```text
    你好，小泽
    ```

### 3.3 函数参数

- **参数声明：** 函数也可以通过 `param()` 接收外部参数。

    ```pwsh
    function Add-Number {
        param(
            [int]$A,
            [int]$B
        )

        return $A + $B
    }
    ```

- **函数调用：** 通过 `-A` 和 `-B` 分别传入两个整数。

    ```pwsh
    Add-Number -A 10 -B 20
    ```

- **运行结果：**

    ```text
    30
    ```

### 3.4 开关参数

- **声明方式：** `[switch]$HashOnly` 表示一个布尔开关参数。

- **传入开关：** 命令中写了 `-HashOnly`，参数值就是 `$true`。

- **省略开关：** 命令中没有写 `-HashOnly`，参数值就是 `$false`。

## 四、脚本级 `param()` 的位置

### 4.1 正确位置

- **位置要求：** 脚本级 `param()` 通常必须位于脚本开头，也就是第一条可执行语句之前。

    ```pwsh
    [CmdletBinding()]
    param(
        [string]$IsoPath
    )

    Write-Host $IsoPath
    ```

- **前置内容：** 通常只有以下内容可以出现在 `param()` 之前。

    - 注释。

    - `#Requires`。

    - `[CmdletBinding()]` 等属性声明。

### 4.2 错误位置

- **错误原因：** 不能先执行普通代码，再声明 `param()`。

    ```pwsh
    Write-Host "开始"

    param(
        [string]$IsoPath
    )
    ```

## 五、参数约束与校验

### 5.1 必填约束

- **默认行为：** 参数默认是可选的，因此通常不需要显式编写 `Mandatory = $false`。

- **必填声明：** `[Parameter(Mandatory = $true)]` 表示调用时必须提供该参数，也可以简写为 `[Parameter(Mandatory)]`。

    ```pwsh
    param(
        [Parameter(Mandatory)]
        [string]$IsoPath
    )
    ```

- **正常调用：**

    ```pwsh
    .\inject.ps1 -IsoPath "C:\virtio-win.iso"
    ```

- **缺少参数：** PowerShell 不一定直接报错，也可能暂停执行并进入交互式询问。

    ```text
    Supply values for the following parameters:
    IsoPath:
    ```

- **能力边界：** `Mandatory` 只要求调用者提供参数，不代表参数内容一定有效，也不一定能完全阻止空内容。

### 5.2 空值校验

- **校验目的：** 如果参数不仅必填，还不能是 `$null` 或空字符串，可以同时使用 `[ValidateNotNullOrEmpty()]`。

    ```pwsh
    param(
        [Parameter(Mandatory)]
        [ValidateNotNullOrEmpty()]
        [string]$Name
    )
    ```

- **约束结果：**

    - 必须提供 `Name`。

    - `Name` 不能是 `$null`。

    - `Name` 不能为空字符串。

### 5.3 集合校验

- **校验目的：** `[ValidateSet(...)]` 用来限定参数值只能从指定集合中选择。

    ```pwsh
    param(
        [ValidateSet("viostor", "vioscsi")]
        [string]$DriverType
    )
    ```

- **允许取值：**

    ```pwsh
    .\install.ps1 -DriverType viostor
    .\install.ps1 -DriverType vioscsi
    ```

- **非法取值：**

    ```pwsh
    .\install.ps1 -DriverType netkvm
    ```

- **校验结果：** 传入集合之外的值时，PowerShell 会报告参数验证错误。

## 六、组合使用

### 6.1 完整示例

- **组合关系：** `[CmdletBinding()]` 提供 Cmdlet 风格的公共参数，`param()` 则声明脚本自己的参数及校验规则。

    ```pwsh
    [CmdletBinding()]
    param(
        [Parameter(Mandatory = $true)]
        [ValidateSet("viostor", "vioscsi")]
        [string]$DriverType
    )

    Write-Verbose "正在安装 $DriverType 驱动"
    Write-Host "选择的驱动类型：$DriverType"
    ```

- **运行方式：** 使用 `-Verbose` 显示详细日志，并通过 `-ErrorAction Stop` 让运行时错误立即终止脚本。

    ```pwsh
    .\install.ps1 -DriverType viostor -Verbose -ErrorAction Stop
    ```
