# Go 中的 `url.URL`：结构化处理 URL

## 一、`url.URL` 是什么，解决什么问题

- **类型定位：** `url.URL` 是 Go 标准库 `net/url` 包中定义的结构体类型。

- **存在的问题：** URL 包含协议、主机、路径和查询参数等结构，还涉及特殊字符编码；使用普通字符串手动解析和拼接容易出错。

- **解决方案：** `url.URL` 把 URL 文本拆成结构化字段，使程序可以安全地读取、修改、编码并重新生成 URL。

- **使用示例：** URL `https://alice:123@example.com:8080/users/42?active=true#profile` 可以拆成以下部分：

    ```go
    u, err := url.Parse(
        "https://alice:123@example.com:8080/users/42?active=true#profile",
    )
    if err != nil {
        log.Fatal(err)
    }

    fmt.Println(u.Scheme)   // https
    fmt.Println(u.User)     // alice:123
    fmt.Println(u.Host)     // example.com:8080
    fmt.Println(u.Path)     // /users/42
    fmt.Println(u.RawQuery) // active=true
    fmt.Println(u.Fragment) // profile
    ```

## 二、常用函数与方法

### 2.1 创建 URL 对象

- **创建方式：** 一般使用 `net/url` 包中的 `url.Parse` 函数把字符串解析成 `*url.URL`；只有明确知道每个字段的含义时，才直接创建 `url.URL`。

    ```go
    u, err := url.Parse(
        "https://api.example.com:8080/vms/123?force=true",
    )
    if err != nil {
        log.Fatal(err)
    }

    directURL := url.URL{
        Scheme: "https",
        Host:   "api.example.com:8080",
        Path:   "/vms/123",
    }
    ```

### 2.2 读取 URL 的组成

- **读取方式：** 通过 `Scheme`、`Host`、`Path` 等字段读取 URL 的组成，通过 `Hostname()` 和 `Port()` 分别获取主机名和端口。

    ```go
    fmt.Println(u.Scheme) // https
    fmt.Println(u.Host)   // api.example.com:8080
    fmt.Println(u.Path)   // /vms/123
    fmt.Println(u.Hostname()) // api.example.com
    fmt.Println(u.Port())     // 8080
    ```

### 2.3 读取和修改查询参数

- **操作流程：** 使用 `Query()` 读取参数，通过 `Get()`、`Set()` 操作参数，再用 `Encode()` 写回 `RawQuery`，最后调用 `String()` 生成完整 URL；特殊字符会被自动编码。

    ```go
    query := u.Query()

    query.Set("mode", "online")
    u.RawQuery = query.Encode()

    fmt.Println(u.String())
    // https://api.example.com:8080/vms/123?force=true&mode=online
    ```
