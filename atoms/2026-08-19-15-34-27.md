# git merge --squash

- **操作步骤：**

    ```bash
    git switch main
    git merge --squash <xxx分支名>
    git commit -m "xxx"
    ```

- **`--squash` 的作用：** 把目标分支上的全部改动合并到当前分支的工作区并暂存，你再手动执行一次 `git commit`，`main` 上就只增加 1 个提交，汇总该分支上的所有改动。
