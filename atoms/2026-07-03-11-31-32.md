# Linux PCI 地址如何定位硬件设备

- ![[Linux PCI 地址与多口网卡命名关系图解：从 Bus、Device 到 Function.png]]

## 一、先把 PCI 地址理解成硬件位置编号

- **位置编号：** PCI/PCIe 设备在 Linux 里都有自己的 PCI 地址，用来标记这个硬件在系统里的位置。

    ```text
    一台机器内部

    CPU / 内存
       |
       | 通过主板上的 PCIe 通道连接各种硬件
       |
    PCIe 连接体系（硬件设备的位置编号）
       |
       |-- 位置 01:00.0  -> 网卡
       |
       |-- 位置 02:00.0  -> 磁盘控制器
       |
       |-- 位置 03:00.0  -> 显卡
       |
       |-- 位置 04:00.0  -> USB 控制器
    ```

## 二、PCI 和 PCIe 是什么

- **PCI 定义与作用：** PCI 全称是 Peripheral Component Interconnect（外设组件互连），这里的外设就是电脑里的扩展硬件，比如网卡、显卡、NVMe SSD、声卡、RAID 卡；这些硬件通常通过 PCIe 接到 CPU 或芯片组上。

- **PCI 与 PCIe 关系：** PCIe 是 PCI Express，是更新、更快的一代 PCI 标准；现在日常说 PCI，很多时候实际是在说 PCIe。

## 三、PCI 地址怎么看

- **地址格式：** PCI 地址通常写成 `bus:device.function`，例如 `03:00.0`。

    ```text
    03      : 00      . 0
    bus       device    function
    总线号     设备号      功能号
    ```

## 四、Linux 如何发现 PCI 设备

- **扫描过程：** Linux 启动时，内核里的 PCI 子系统会扫描 PCI 总线，检查主板有哪些 PCI 设备，然后识别设备类型并加载对应驱动。

- **查看命令：** Linux 上可以用 `lspci` 查看机器上的 PCI/PCIe 设备。

    ```bash
    lspci
    ```

## 五、多口网卡为什么有多个地址

- **多功能设备：** 一张网卡如果有多个端口，可能会在 PCI 里暴露成多个 function。

    ```text
    0000:03:00.0
    0000:03:00.1
    0000:03:00.2
    0000:03:00.3
    ```

- **端口对应关系：** 这些地址可能属于同一张多口网卡；大白话就是“一块网卡上有多个网络口，每个口在 PCI 地址里对应一个 function 编号”。
