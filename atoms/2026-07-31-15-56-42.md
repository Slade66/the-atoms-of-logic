# Windows Server 2008 的 PowerShell 版本

- **默认版本：** Windows Server 2008（包括 SP1 / SP2）默认搭载 PowerShell 1.0；Windows Server 2008 R2 默认搭载 PowerShell 2.0。

- **升级方式：** 安装 Windows Management Framework（WMF）2.0 后可使用 PowerShell 2.0；安装 WMF 3.0 后可使用 PowerShell 3.0，后者支持 Windows Server 2008 SP2。

- **查看当前版本：** 打开 PowerShell 并执行 `$PSVersionTable`，其中 `PSVersion` 字段即为当前版本。

    ```text
    Name                           Value
    ----                           -----
    PSVersion                      2.0
    ```
